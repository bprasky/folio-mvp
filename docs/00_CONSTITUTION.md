# Constitution

## 0. Purpose of This Document
This Constitution defines the unchanging principles, boundaries, and decision framework of Folio.
If a decision, feature, or suggestion conflicts with this document, the Constitution wins.

## 1. What Folio Is
Folio is a professional, merit-based interior design ecosystem.
It is the central hub where designers publish and manage real work, vendors connect products to authentic usage, and individuals move from inspiration to execution.
Folio exists to democratize design by replacing fragmented, pay-to-play, and informal workflows with a trusted, structured, and intelligent platform.

## 2. What Folio Is Not
Folio is not a generic social media platform, a content-first engagement farm, a pay-to-play visibility marketplace, or a mass e-commerce catalog.
If a feature primarily optimizes for virality, engagement without attribution, or time-on-platform without action, it is misaligned with Folio.

## 3. The Primary Gravity Well
Designers are the primary gravity well of Folio.
All other user types exist in relation to designer activity. If a tradeoff must be made, designers come first.

## 4. Editorial Is a Status Achieved by a Posted Project
Editorial in Folio is not a separate content system and not a parallel publishing track.
Editorial is an earned status that a Posted Project can achieve once it reaches defined levels of recognition and engagement.

Recognition signals may include:
- Saves
- Likes
- Meaningful engagement patterns
- Other merit indicators defined by the system

Editorial status exists to:
- Elevate exceptional work without gatekeeping
- Create a high-signal layer that rewards merit
- Increase discoverability of proven projects
- Preserve authorship and product attribution

In early phases, Editorial may use a hybrid model where engagement signals qualify a project and a curator confirms elevation. The long-term target is merit-based automatic recognition.
Curation may refine presentation (e.g., editions), but recognition always precedes promotion.

### 4.1 Canonical Content Taxonomy
Folio recognizes the following canonical states:
- Project: A private or in-progress body of work owned by a designer.
- Posted Project: A project that has been made public. Public visibility is required for recognition.
- Editorial Project: A Posted Project that has achieved Editorial status through merit-based recognition.
- Editorial Edition Project: An Editorial Project selected into an edition through automated and/or curated processes.

Editorial is a status, not a separate content type in concept. Implementation details may vary, but this taxonomy is binding.
