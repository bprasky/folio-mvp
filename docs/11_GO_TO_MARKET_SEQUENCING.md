# 11_GO_TO_MARKET_SEQUENCING

## Purpose
This document defines Folio's phased go-to-market strategy, showing how we move from initial wedge to full ecosystem systematically.

## The Wedge Strategy

Folio's vision is to become the operating system of interior design.
But we're not building everything at once.

We're starting with the highest-value, lowest-friction wedge: **Designer publishing + Instagram sharing**

## Why This Wedge?

1. **Immediate designer value** - Better portfolio than Instagram grid
2. **Instant distribution** - Instagram becomes our marketing channel
3. **Content corpus** - Creates the feed that attracts future users
4. **Data foundation** - Engagement signals power Atelier intelligence
5. **Proof point** - Validates editorial AI before expanding scope

## The Expansion Path
```
Designer Publishing (Mo 1-6)
    ↓
Workflow Integration (Mo 6-12)
    ↓
Vendor Attribution (Mo 12-18)
    ↓
Event Layer (Mo 18-24)
    ↓
Full Marketplace (Year 2+)
```

Each phase unlocks the next. We don't move forward until the current phase is validated.

## Phase 1: Designer Publishing Wedge (Months 1-6)

**What we're building:**
- Designer portfolio pages
- Project post creation with editorial layouts
- AI-powered layout generation from images
- Instagram cross-posting integration
- Basic engagement tracking (saves, likes, views)
- Simple discovery feed

**What we're NOT building yet:**
- Full project management suite
- Vendor SaaS dashboard
- Client marketplace
- Complex AI rendering
- Event ticketing platform
- Monetization features

**Success metrics:**
- 5-20 designers actively publishing 1-2 projects/month
- 50%+ of designer Instagram posts originate from Folio
- Measurable traffic from Instagram → Folio
- Strong qualitative feedback on editorial quality

**Go-to-market tactics:**
- Direct outreach to target designers
- "Founding designer" early access program
- Design festival presence (booth/speaking)
- PR in design publications
- Instagram as primary distribution channel

## Phase 2: Workflow Integration (Months 6-12)

**What we're building:**
- Project workspace (moodboards, product libraries)
- Product tagging system
- AI pre-rendering of unbuilt projects
- Designer-client collaboration features
- Enhanced project management tools

**Success metrics:**
- 50+ designers using Folio for active project work
- 200+ total designer accounts
- Product tagging data accumulating
- Designers reporting workflow time savings

**Go-to-market tactics:**
- Case studies from Phase 1 designers
- Workflow webinars and demos
- Expansion to adjacent design communities
- Begin vendor outreach based on tag data

## Phase 3: Vendor Attribution (Months 12-18)

**What we're building:**
- "You were tagged" vendor notification system
- Vendor profile pages and analytics
- Product catalog upload tools
- Vendor-designer messaging
- Basic vendor SaaS tiers

**Success metrics:**
- 20+ active vendor accounts
- Vendors monitoring analytics weekly
- First vendor revenue (SaaS subscriptions)
- Product catalog reaching 1000+ SKUs

**Go-to-market tactics:**
- Data-driven vendor outreach (tagged products)
- Trade show presence
- Vendor case studies showing attribution ROI
- PR in industry trade publications

## Phase 4: Event Integration (Months 18-24)

**What we're building:**
- Event listing and RSVP system
- Event-based discovery features
- Physical-digital attribution loop
- Event analytics for vendors

**Success metrics:**
- 10+ design events listed
- Event-driven sign-ups measurable
- Vendor event ROI tracking active

## Phase 5: Full Marketplace (Year 2+)

**What we're building:**
- Individual user onboarding
- Designer hiring marketplace
- Full monetization across all user types
- Advanced AI features
- API and integration ecosystem

## Current Focus: The First 5-20 Designers

Our immediate goal is recruiting and supporting 5-20 founding designers.

**Selection criteria:**
- Active on Instagram (proves they value sharing)
- Portfolio of completed projects
- Diverse aesthetics (test AI across styles)
- Willing to give detailed feedback
- Professional practice (not students/hobbyists)

**What we're offering:**
- Founding designer status and recognition
- Free premium features during beta and beyond
- Direct influence on product direction
- White-glove onboarding support
- Priority for future editorial features

**The ask:**
- Publish 1-2 completed projects on Folio
- Share to Instagram with Folio attribution
- Provide honest feedback on workflows
- Participate in monthly feedback sessions

**Success definition:**
By month 6, we have 5-20 designers who:
1. Actively publish projects on Folio
2. Share majority of Instagram posts from Folio
3. Provide enthusiastic testimonials
4. Are willing to be reference customers
5. Show measurable engagement on their posts

This cohort becomes the foundation for Phase 2 expansion.

## What We Learn From Each Phase

**Phase 1 teaches us:**
- Which editorial layouts resonate
- What engagement signals predict quality
- How Instagram integration affects adoption
- What designer personas convert best
- Whether our AI quality meets professional standards

**Phase 2 teaches us:**
- Which workflow features matter most
- How product tagging affects designer behavior
- Whether AI rendering drives value
- What collaboration features are essential
- Which vendor attribution data is most valuable

**Phase 3 teaches us:**
- Vendor willingness to pay for attribution
- Which analytics features drive vendor retention
- How to price vendor tiers
- What product data quality is required
- Whether vendor-designer connections convert

**Phase 4 teaches us:**
- Event ROI for platform growth
- Physical-digital loop effectiveness
- Event-based monetization potential

Each phase de-risks the next.

## Why This Sequencing Works

1. **Clear value at each stage** - Every phase solves a real problem
2. **Natural expansion** - Each phase creates demand for the next
3. **Data compounds** - Earlier phases feed intelligence for later ones
4. **Capital efficient** - Prove wedges before expanding scope
5. **Reversible decisions** - Can adjust based on learning

## Risk Mitigation

**Phase 1 risks:**
- Designers don't see value vs. Instagram → Mitigation: White-glove support, founding designer benefits
- AI layouts aren't good enough → Mitigation: Manual override, designer editing tools
- Instagram integration breaks → Mitigation: Manual sharing fallback

**Phase 2 risks:**
- Workflows too complex → Mitigation: Optional features, progressive disclosure
- Product tagging feels like work → Mitigation: AI assistance, clear vendor attribution payoff
- AI rendering disappoints → Mitigation: Start with simple use cases, manual fallback

**Phase 3 risks:**
- Vendors won't pay → Mitigation: Free tier with attribution, prove value first
- Product catalog upload too hard → Mitigation: White-glove service, scraping tools
- Not enough designer data → Mitigation: Phase 2 must succeed first

## Conclusion

Folio's full vision requires a massive ecosystem. But that ecosystem must be built methodically, validating each layer before expanding.

We start with the smallest viable wedge that creates real value: helping designers publish and share their best work.

From there, we expand based on evidence, not assumption.

This is how platforms are built to last.
