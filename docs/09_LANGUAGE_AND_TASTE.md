# 09_LANGUAGE_AND_TASTE

## Purpose
This document defines how Folio speaks, labels, and presents itself.

Language and taste are treated as structural components, not decoration.

## Language Principles
Folio language is:
- Professional
- Calm
- Precise
- Non-performative
- Non-hyped

Folio avoids language optimized for:
- Virality
- Trendiness
- Emotional manipulation
- Artificial urgency

## Canonical Terminology
The following terms are canonical and binding:
- Designer
- Vendor
- Individual
- Project
- Posted Project
- Editorial Project
- Edition

Deprecated or ambiguous terms must be explicitly rejected elsewhere.

## Editorial Tone
Editorial tone is:
- Observational, not promotional
- Respectful of craft
- Focused on work, not personality

Editorial does not:
- Gossip
- Speculate
- Inflate importance
- Manufacture narrative

## UI and Copy Taste
Folio UI and copy should:
- Feel intentional, not busy
- Prefer clarity over cleverness
- Reduce cognitive load
- Let work speak before commentary

If something draws attention to itself rather than the work, it is likely off-brand.

## Consistency Over Cleverness
Consistency is prioritized over novelty.

A consistent system builds trust.
A clever system ages quickly.
