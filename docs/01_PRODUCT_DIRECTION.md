# 01_PRODUCT_DIRECTION

## Purpose
This document defines where Folio is going without prescribing how it is built or when it is delivered.

It establishes directional intent, not roadmap commitments.

## Product Direction
Folio is moving toward becoming the system of record for interior design work.

The platform is evolving from:
- A place to post projects
to
- A system that captures, structures, and elevates real design activity

## Directional Pillars

### From Inspiration to Execution
Folio prioritizes workflows that move users:
- From browsing → to decision
- From ideas → to real products
- From admiration → to collaboration

Any feature that stops at inspiration without enabling action is incomplete.

### From Visibility to Recognition
Folio does not optimize for exposure alone.

The platform recognizes:
- Consistent contribution
- Authentic usage
- Earned engagement

Status (e.g., Editorial) is achieved through participation and merit, not promotion.

### From Fragmentation to One System
Folio continues to consolidate:
- Projects
- Editorial
- Products
- Events
- AI assistance

Into a single shared system, rather than disconnected tools.

### From Manual to Intelligent
Over time, Folio will rely less on manual intervention and more on:
- Structured signals
- Pattern recognition
- Assistive AI

Automation follows trust, not the reverse.

## Phased Product Strategy

Folio's vision is comprehensive, but we're building it systematically in phases. Each phase validates before expanding. We don't move forward until current phase shows traction and product-market fit.

**Phase 1: Designer Publishing Wedge (Months 1-6)**
- Designer portfolios with project posts
- Editorial-quality auto-layouts from uploaded images
- One-click Instagram sharing with Folio attribution
- Basic engagement signals (saves, likes, views)
- Success metric: 5-20 designers actively publishing
- Why first: Immediate value, creates content corpus, validates editorial AI, drives traffic via Instagram

**Phase 2: Workflow Integration (Months 6-12)**
- Project workspace (moodboards, product libraries, client boards)
- Product tagging with vendor attribution
- AI-assisted pre-rendering of unbuilt projects using real products
- Basic collaboration features
- Success metric: Designers manage 50%+ of active projects in Folio
- Why second: Requires deep collaboration, creates vendor data, pre-rendering = shareable content

**Phase 3: Vendor Attribution Layer (Months 12-18)**
- "You were tagged" vendor notification emails
- Vendor profiles and analytics dashboards
- Vendor product catalog uploads
- Vendor-designer messaging
- Success metric: 20+ vendors actively monitoring presence

**Phase 4: Event Integration (Months 18-24)**
- Event listings and RSVP system
- Physical-digital loop activation
- Event-based vendor/designer discovery

**Phase 5: Marketplace Effects (Year 2+)**
- Individual user onboarding
- Full monetization activation
- Complete ecosystem maturity

Each phase validates before expanding. We don't move forward until current phase shows traction and product-market fit.

## Non-Goals

Those belong elsewhere.
