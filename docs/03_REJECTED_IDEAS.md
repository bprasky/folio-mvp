# Rejected Ideas

## Purpose

This document archives ideas, features, or approaches that have been explicitly considered and rejected. Used to prevent revisiting decisions and to understand historical context.

## Sections

- Rejected Features
- Alternative Approaches Considered
- Rationale for Rejection
- Conditions for Reconsideration

### Rejected: Editorial as a Separate Publishing System
We reject an editorial system that operates as a standalone CMS or submission-based workflow independent of project posting and recognition.
Editorial on Folio is an earned status of a Posted Project. Editions serve as an additional curation layer, not a replacement publishing path.
